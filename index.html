Side project · 2026

Nova's Translator

A desktop web app I built for studying abroad. It listens to the lecture, shows Traditional Chinese subtitles live with the original text underneath, and after class turns the whole transcript into Markdown notes.

  • Real-time pipeline. Microphone → Mistral Voxtral speech recognition → sentence segmentation → Mistral translation, saved to disk as it goes.
  • Slide-aware translation. Reads the uploaded PDF or PPTX first to learn the course domain and its terminology, so technical terms stay consistent.
  • Term corrections. Fix a mistranslated term once and it applies to later translations and notes, saved per course.
  • One-click notes. Summary, detailed notes, assignment reminders and a glossary, with flashcard export to Anki and Quizlet and sync to Notion.
  • Built for real classrooms. Auto-reconnects after network or microphone drops, keeps the Mac awake while recording, and resumes after a page refresh.
  • Python
  • Streamlit
  • Mistral API
  • Voxtral Realtime
  • Notion API
